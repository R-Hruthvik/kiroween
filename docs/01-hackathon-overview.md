## Eligibility

- Age of majority in country of residence; teams up to **3 members**
- Not open to: Quebec (Canada), Argentina, Brazil, Italy, Philippines, Russia, Cuba, Iran, North Korea, Syria, Belarus, Crimea/DNR/LNR, UAE, comprehensively sanctioned countries; employees of AWS/Devpost and their families
- AI model/feature availability varies by region — entrant's responsibility

## What to Build

**A working software application that uses Kiro** (IDE, CLI, Web, and/or Kiro Crew). Insufficient Kiro use = disqualification. Submit into ONE category:

1. **Resurrection** — Bring a favorite dead technology back to life; reimagine obsolete tech with today's innovations.
2. **Frankenstein** — Stitch seemingly incompatible technologies into one surprisingly powerful app.
3. **Skeleton Crew** — Build a lean skeleton code template; show versatility with **2 distinct applications** built from it.
4. **Costume Contest** — Any app, but with a haunting, polished, unforgettable UI; spooky design that enhances function.

**New projects only** — must be built during the Submission Period. Frameworks/libraries/templates allowed but pre-existing code must be disclosed.

## Submission Requirements

- Public **GitHub** repo (NOT GitLab/BitBucket) — all source, assets, instructions
- Must include an **open-source license** detectable in repo About section
- Repo **must contain `/.kiro` directory** at root (specs, hooks, steering) — must NOT be in `.gitignore`
- Skeleton Crew: repo must contain **2 separate repo folders** for the 2 apps
- URL to working app; judges-only credentials in Devpost form
- Text description of features
- **Demo video:** < 3 minutes, YouTube public, shows app on its target device, no third-party trademarks/copyrighted music
- **Kiro usage write-up:** how specs/hooks/steering/MCP/Crew/powers/PBT were used — judges score Kiro depth explicitly
- Select category + any Bonus Prizes wanted

## Judging Criteria (each 20% — 10 points, 50 total)

1. **Potential Impact** — solves a real problem for a real audience; would someone actually use it?
2. **Technological Implementation** — how thoroughly/skillfully Kiro was used; variety of Kiro tools; experimentation
3. **Design** — complete, coherent product experience, not a proof of concept; intuitive + polished
4. **Innovation/Idea** — creative, novel; unusual tech/datasets combined uniquely
5. **Presentation** — video shows end-to-end working; clear problem/solution story; memorable

Tie-break: judges re-score with doubled maximums until resolved.
