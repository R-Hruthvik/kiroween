## Category verdicts

**Resurrection — saturated.** Teletext (8+), HyperCard (15), BBS (6), RSS (7), GeoCities, MySpace/Orkut, fax, floppy, cassette, IRC, COBOL, ELIZA, Encarta, punch cards all taken. Survives only with a real modern constraint, not nostalgia. Top uniques: Weatherfax (HF radiofax decoder), Answerback (telex over IP with real ITA2 handshake), Baudot Bridge (TTY/TDD → RTT accessibility), 3615 Bharat (Minitel for feature phones), Bang Path (UUCP store-and-forward for rural clinics).

**Frankenstein — open ground is live transports and cross-domain semantics.** Dead objects are all claimed (fax, rotary, cassette, floppy, punch card, Morse, Modbus, CAN, braille). Untouched: MIDI/OSC/DMX/timecode, HL7 v2, ASTM E1394, HP-GL, POCSAG, APRS, SWIFT MT, MARC21, XMODEM, ZPL. Top: CueForge, TubeMQ, **LipiSetu**, LabBridge, PlotForge.

**Skeleton Crew — crowded shape, one open beat.** 7+ template+2-apps entries this cohort. Nobody sells "one spec line → hook scaffolds a complete capability" as a live demo moment. That is the open 20%. Top: Replay Kit, Choice Kit, Voice Kit, Forge Kit, Cadence Kit.

**Costume Contest — "neglected X becomes a ghost" and "séance" are saturated.** 7+ ghost-frame entries, 7+ séance entries, retro-OS skins everywhere. Survives only if the interface *is* the readout. Top: The Portrait, Side Project Hospice, The Wake, Curse Breaker, Interrogation Room.

## Cross-category shortlist (my ranking)

1. **LipiSetu** (Frankenstein) — legacy Indian font encodings (Kruti Dev/Chanakya/ISCII) → Unicode Devanagari, so court and government archives become searchable. Real audience, real harm fixed, round-trip PBT is the Kiro showcase, no crowding, zero infra cost, India-specific advantage. Demo: mojibake judgment → legible, searchable text.
2. **Weatherfax** (Resurrection) — decode HF radiofax with the phone mic, paint the synoptic chart offline, then a plain-language cyclone warning. Zero crowding, DSP + PBT, cyclone relevance for India. Demo risk: needs a sample WAV fallback.
3. **CueForge** (Frankenstein) — one cue engine driving DMX + MIDI + SMPTE; AI compiles "thunderstorm cue". Great showpiece, but judges may read it as an AV tool.
4. **The Portrait** (Costume) — health check-in whose only dashboard is a painted face that rots with bad weeks. `dorian gray` = 0 results. Highest design ceiling, weakest objective impact.
5. **Replay Kit** (Skeleton Crew) — typed event log + deterministic replay, with the hook adding an event type live. Best shot at the open "hook scaffolds a capability" beat.
