# Kiroween 2025 Winners — What Won and Why

Source: kiroween-2025.devpost.com project gallery (747 submissions, 66 winners) + GitHub (InteractionKit).

## Grand Prize ($30,000)

**InteractionKit** — `github.com/Harpita-P/Kiro-InteractionKit`
A **Skeleton Crew-style template**: clean Python starter kit that turns hand/face/head tracking (MediaPipe + OpenCV) into simple controls for games and accessibility apps. Shows versatility with **2 distinct apps** (Math-O-Lantern game + Holo-Board drawing tool). Uses Kiro **hooks to auto-generate new gesture handlers** from specs. 21 stars, MIT license.

**Lesson:** a well-scoped reusable template that *demonstrates Kiro automation* (spec → hooks → generated gestures) beat flashier one-off apps.

## Patterns in winners

1. **Real problem + real audience** beats pure novelty (Faxi, rumorNet, Splice).
2. **Category name literally realized** — "Resurrection" = actual dead tech (fax, COBOL, ELIZA, KaiOS); "Frankenstein" = actual stitch of incompatible tech.
3. **Deep Kiro feature showcase** (specs, hooks, steering, MCP) is a scored criterion — winners wrote it up prominently.
4. **Memorable demo/video** — spooky twist keeps the Presentation score.
5. **Dev tools / B2B utility** (Splice, UnitSet) can win — judges are industry devs.
6. Games were common but only won when they carried a real purpose (Zombie Blaster → security remediation).
